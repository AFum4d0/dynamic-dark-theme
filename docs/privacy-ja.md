# プライバシーポリシー — Dynamic Dark Theme

[English](privacy.md)

最終更新: 2026-09-22

Dynamic Dark Theme は、**外部のサーバへデータを送りません**。開発者や第三者へ、閲覧内容・設定・統計を送信する仕組みはありません。テレメトリ、解析、クラッシュレポート、アカウント連携、リモートコードの取得は、いずれもありません。

## 端末内に保存するもの（`chrome.storage.local`、同期しません）

| 内容 | 詳細 |
|---|---|
| 設定 | パレット、面のスタイル、画像の扱い（SVG のロゴを含む）、適用モード、ブラックリスト・ホワイトリスト、補正の仕組みを止めたサイト |
| 訪れたサイトの記録 | 拡張機能を適用した（または適用しないと判断した）ホスト名と、サイト別の有効・無効の状態。**「ウェブの閲覧履歴」に当たります**。端末内にだけ保存し、外へ出しません。ポップアップの「訪問先の記録を消す」で消せます（手動で設定したサイトは残ります） |
| 修復ルール | 「魔法の杖」で、あなたが作ったルール（ホスト名、CSS セレクタ、色の宣言） |
| スタイルシートのキャッシュ | ページが読み込む外部 CSS の写し（上限 4 MB） |
| 内部の失敗記録 | 登録の失敗など（最大 30 件） |

拡張機能を削除すると、これらはすべて消えます。

## 通信

拡張機能が、自分でネットワークへ出る通信は、次の 3 つだけです。どちらも、**ページがすでに読み込んでいるリソースを、Cookie なしで 1 回取り直す**ものです。

1. **外部スタイルシートの取得:** 別のオリジンの CSS は、ページ内のスクリプトからは読めません。そのため、バックグラウンドから、GET で取得します（`credentials: omit`）。
2. **画像の取得と解析:** 白地の写真、地図、ロゴの判別のために、ページ上の画像を取得して、小さく縮めて、明るさなどの統計だけを計算します。画素そのものは、ページへ返しません。
3. **SVG のロゴの取得:** 暗い面の上で見えにくい SVG のロゴ（`<img>` で表示されているもの）の色を直すために、その SVG の本文を取得します（上限 256 KB）。SVG の種類でないものは使いません。ポップアップの「SVG のロゴ」を「そのまま（従来）」にすると、取得しません。

いずれも、拡張機能が有効になっているサイトからの要求だけを扱います。LAN、ループバック、リンクローカル、メタデータ用のアドレスへの取得は、拒否します。

## 「画面を保存」

ポップアップの「診断を保存」「再現用に保存」を押したときだけ動きます。ファイルとして、あなたの端末に書き出すだけで、送信しません。

- **既定で、ページのすべての文字を伏せ字にします**（長さと文字の種類は残します）。チェックを外すと、アカウント・住所・ナビゲーションなどの領域だけを伏せ、残りはそのまま入ります。
- URL のクエリと `#` 以降は、含めません。
- スクリプト、`iframe`、入力欄の値、Cookie は、含めません。
- 「再現用」は、ページの構造と CSS を含みます。共有する前に、中身を確認してください。

## ページから読むもの

計算済みのスタイル、要素の大きさ、クラス名、ID、スタイルシートの本文です。ページの本文の文字は、コントラストの判定などのために、その場で一時的に読みます。保存も送信もしません。

## 問い合わせ

サポート・不具合の報告・プライバシーの問い合わせは、`aswdf2b7+ddt-support@gmail.com` へお送りください（件名に「[DDT Support]」を含めると、見分けやすくなります）。ポップアップの「フィードバック / サポート」で開くページから、宛先・件名・本文のひな形をコピーできます。ひな形に入るのは、版数・Chrome の主要版・OS の名前だけです。

## 支援のリンク

ポップアップとサポートのページに、任意の支援のリンク（Buy Me a Coffee）があります。押したときだけ、そのページを新しいタブで開きます。拡張機能から、支援のサービスへ、データは送りません。
